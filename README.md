# 微信防撤回 3.2.0

让收到的消息留在眼前。新版采用深色界面和青蓝色按钮，把常用操作整理为「检查微信 → 选择效果 → 开启使用」。

## 怎么用

1. 双击 `WeixinAntiRevoke.exe`，等待自动检查完成。
2. 选择「保留消息 + 撤回提醒」或「只保留消息」。
3. 在屏幕右下角右键点击微信图标，选择「退出」，再回来点击「开启防撤回」。只关闭聊天窗口还不够。
4. 如果 Windows 询问是否允许，请选择「是」。工具重新打开后，再点击一次要执行的操作。
5. 重新打开微信，用一条测试消息确认效果。撤回提醒可能需要切换聊天后才显示。

已经开启时，界面会显示当前效果；选择另一张卡片即可切换。想恢复微信原来的行为，退出微信后点击「关闭防撤回」。

## 常见问题

- **找不到微信？** 点击「手动查找微信」，选择平时用来打开微信的 `Weixin.exe`。
- **微信更新了？** 回来点击「重新检查」。工具会在电脑上检查新版微信是否可用，不需要手动填写版本号。未来部分版本仍可能需要更新本工具。
- **显示暂时无法开启？** 本次检查不会更改微信。可以更新本工具后重试；需要别人帮助时，在「使用帮助」里点击「复制检查信息」。
- **关闭按钮不能点？** 可能尚未开启，或恢复所需的备份不可用。请保留微信安装目录里的备份文件，不要自行删除。

微信检查在本机完成，不读取聊天记录。程序会连接本项目的 GitHub 发布页检查软件更新。复制检查信息时会包含微信所在位置、文件检查结果等排查资料。

## 软件更新

程序启动后会在后台检查新版。右上角出现「发现新版 · 点击更新」时，点击后可查看说明，再选择「立即更新」或「稍后再说」。也可随时点击「检查软件更新」。

确认更新后会下载、检查文件、保留旧版并重新打开工具。下载期间可取消；连接不上时可继续使用当前版本。更新软件不需要退出微信。旧版会保留在程序旁，文件名中带 previous。新版启动失败时会尝试恢复旧版。

## 文件说明

`WeixinAntiRevoke.exe` 可单独复制运行，无需另外下载组件。适用于 64 位 Windows 和 .NET Framework 4.8（Windows 10/11 通常已具备）。

使用新版图标：关闭旧版工具，再打开此处的新版程序。如果之前固定过任务栏图标，请先取消固定旧版，再将新版固定到任务栏。

源码构建与验证见 `DEVELOPMENT.md`，维护发布见 `RELEASE.md`。
